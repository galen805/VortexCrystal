# VortexCrystal
Simple models for vortex interactions motivated by Juno observations of the polar vortex crystals on Jupiter, see https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2022JE007241 

1) To study the motion of the polar cyclones, contourDynamics.m simulates vortex patch interaction with two examples of ring vortices. The first example is stable, and vortices propagate under mutual advection without merging. In the second example vortices are unstable and merge via deformation. RK2 timestepping is used to better conserve vortex patch area. The contour dynamics code does NOT do any surgery or remeshing, and instead has a simple area cutoff for stability.
2) Estimates of the velocity field for the Jupiter polar vortex crystals are obtained by feature tracking from JIRAM instruments using the method described in https://agupubs.onlinelibrary.wiley.com/doi/abs/10.1029/2018je005555. MATLAB codes `load_and_filter_north.m` and `load_and_filter_south.m` in this folder apply spectral filtering to the raw velocity estimates and save the result as `.mat` files. The script `profiles_plot.m` uses the filtered data to construct tangential velocity profiles for each vortex, and fit the data to the idealized cyclone profiles of https://journals.ametsoc.org/view/journals/atsc/44/9/1520-0469_1987_044_1257_aansot_2_0_co_2.xml by RMSE minimization. Output plots are provided. These processing steps were used to generate figures for the forthcoming manuscript "Mutual Advection and Stability of Jupiter's Polar Vortex Crystals" by Wilcox et al.
3) Using observations of the wind field, a more sophisticated model of vortex mutual interaction and stability `qg15_disk_IVP/qg15disk.py` is implemented in the Dedalus pseudo-spectral code. Vortices are initialized in a disk domain using the idealized profile parameters determined from (3), and allowed to evolve under a variety of conditions. This code is used to produce the experiments described in the forthcoming manuscript "Mutual Advection and Stability of Jupiter's Polar Vortex Crystals" by Wilcox et al. Video output of these experiments are provided in the directory `qg15_disk_IVP/sampleOutput`.
5) Unifying the formation and motion of the cyclones is an area of active study. The Dedalus model `qg15_disk_FD/qg15diskFD.py` simulates the 1.5 layer quasi-geostrophic equations with Ornstein-Uhlenbeck forcing and quadratic drag dissipation, mimicing convective forcing at the polar regions. In the example provided, energy moves up scale to a dipole structure and no vortex crystal emerges, but the numerical setup seems promising for further exploration of the parameter space. Plotting and diagnostic scripts are included.
